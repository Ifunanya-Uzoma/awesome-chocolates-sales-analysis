Awesome Chocolates – Sales and Profitability Analysis

Project Overview

This project involved analysing sales data for Awesome Chocolates to evaluate business performance, understand profitability and identify key sales trends.

I used SQL to query and explore the dataset, followed by Microsoft Excel to perform further analysis and develop interactive dashboards that communicate important business insights.

Tools and Technologies

- SQL: Data querying, filtering and extraction using SELECT and WHERE statements.
- Microsoft Excel: Data cleaning, VLOOKUP, text functions, aggregate functions, PivotTables and PivotCharts.
- Excel Dashboard: Interactive data visualisation and business performance reporting.

Key Performance Indicators

- Total Revenue: $5.59 million
- Total Cost: $1.10 million
- Total Profit: $4.48 million
- Profit per Dollar Spent: $4.05

Key Insights

- Top Performing Country: India generated the highest profit, approximately $878K.
- Top Salesperson: Rafaelita Blaksland recorded the highest sales, approximately $275K.
- Top Performing Product: Organic Choco Syrup emerged as the leading product based on the analysis.

Business Value

The analysis provides insights into revenue generation, cost management and profitability across products, countries and salespeople. These findings can help business stakeholders identify strong-performing areas and make more informed decisions.

Skills Demonstrated

SQL querying | Data Analysis | Data Cleaning | Excel Functions | PivotTables | Data Visualisation | Dashboard Development | Business Insight Communication
